# 10 — Apache-2.0 license

**Decision:** finstore is licensed under Apache-2.0.

**Rationale:**

Apache-2.0 includes an explicit patent grant, which makes it safe to embed in
both open-source and commercial products. It is permissive (no copyleft), OSI
approved, and widely understood.

MIT was considered; Apache-2.0 is preferred specifically for the patent grant,
which matters for a financial data library that may be embedded in products
with IP concerns.

**Consequence:** Contributions are received under Apache-2.0. The `LICENSE`
file is in the repo root.
